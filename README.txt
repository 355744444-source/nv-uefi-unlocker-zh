这是什么
--------------------------------------------------------------
nv-uefi-unlocker 是 UEFI 预驱动层的 NVIDIA GeForce 算力解锁器。
它在系统驱动加载之前接管 GPU 事务、写入速率/算力覆盖值，从而解除
GeForce 卡上的 Tensor 算力限制。

  · 不刷 VBIOS、不改固件、不改驱动文件
  · 从 U 盘启动执行一次事务，结束后链回系统
  · 完全易失：断电 / 冷启动 / 休眠恢复即复原，需要每次重放

使用前提
--------------------------------------------------------------
  · UEFI 启动 + 关闭 Secure Boot
  · 关闭 Windows「快速启动」，之后从系统选「重启」进一次性启动菜单
  · FAT32 U 盘，原有文件先备份
  · 支持范围：Turing(GTX16/RTX20)、Ampere(RTX30)、Ada(RTX40)
    RTX 50 / Pascal / GA100 不在支持范围

三条硬约束
--------------------------------------------------------------
  1) 易失性：断电即复原，每次冷启动需重放。
  2) 失败别重试：出现 STOP 或黑屏卡死，立刻彻底断电、拔 U 盘、
     正常启动，再按手册 08 章排障。
  3) cargo efi 不能解锁：自建时必须用 cargo efi-tx（带 --features tx）。
     cargo efi 编出来的是只读采样程序。
